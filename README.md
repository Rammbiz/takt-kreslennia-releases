# Такт · Креслення для Android: APK

Готові APK «Такт · Креслення» для телефонів і планшетів Android (8 і новіших). Коду програми тут нема.

Поставити вперше: з телефона відкрити останню версію в розділі «Releases» праворуч і завантажити
`TaktKreslennia-<версія>.apk`, тоді відкрити завантажений файл. Android спитає дозволу ставити програми з браузера
(чи з Telegram, якщо APK прийшов туди): дозволити й поставити.

Далі програма сама бере звідси нові версії: під час запуску тихо перевіряє й завантажує, а ставить лише після кнопки
«Оновити» (системне вікно Android). Перевірити вручну: «⋯ › Перевірити оновлення».

У кожному випуску поруч з APK лежить `latest.json`: версія, розмір і SHA-256 файлу. З ним програма звіряє завантажене
й чужого файлу не поставить.
